# Installazione RC7 su OpenSTAManager 2.10.4

1. Verificare che il modulo **Piano dei conti** sia abilitato.
2. Eseguire backup completo di file e database.
3. Controllare `modules/partitario/custom/`.
4. Se contiene file personalizzati non appartenenti a Gestione esercizio, fermarsi: il pacchetto li sovrascriverebbe.
5. Aprire `Strumenti → Aggiornamenti`.
6. Caricare lo ZIP RC7.
7. Aprire Piano dei conti e verificare barra e modale senza eseguire operazioni.

Target esclusivo: OpenSTAManager 2.10.4.
